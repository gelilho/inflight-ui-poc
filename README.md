
  # In-flight experience - Vueling

  This is a code bundle for the In-Flight Experience for Vueling. This covers the comfort of seating, in-flight entertainment, quality of meals, and cabin crew service. 
  
  The original project is available at https://www.figma.com/design/bSUtFj39bcnhVgv3eklEnM/Pantalla-de-vuelo-Vueling.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
